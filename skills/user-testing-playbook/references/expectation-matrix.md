# Expectation matrix

What each kind of user judges the app by, what to watch for, and which personas carry it.

| Expectation | Watch for | Typical personas |
| --- | --- | --- |
| Achieve a goal | Steps to finish, wrong turns, errors, dead ends, final correctness | Achiever, Comparer, Power User |
| Entertain myself | Smoothness, surprise, delight, what to do next, boredom, friction | Entertainer, Explorer |
| Explore and learn | Clear labels, safe undo, helpful empty states, explained jargon | Explorer, First-Timer |
| Compare and decide | Complete info, price clarity, proof, honest claims, easy way back | Comparer, Skeptic |
| Recover from a mistake | Undo, confirmations, clear errors, data kept | Distracted, First-Timer, Rule-Breaker |
| Random or careless use | Crashes, duplicates, lost data, stuck spinners | Random Clicker |
| Interrupted use | Resume, saved drafts, offline messages, session expiry | Distracted, Returning User |
| Stay in control | Consent, privacy, no surprise charges, easy opt-out, no dark patterns | Skeptic |
| Be included | Keyboard, focus, labels, contrast, zoom, motion, target size | Accessibility User, One-Thumb |
| Feel fast | First response under ~1 s, progress for slow work, no layout jumps | Skimmer, One-Thumb |
| Get help | Findable help, useful errors, a human route | Helper-Seeker |
| Share and return | Shared view works for a stranger, nothing private leaks, returns to the same place | Sharer, Returning User |
| Understand fast | Purpose clear in 5 seconds, right audience filtering | Wrong-Audience, Skimmer |

How to build the matrix: rows are scenarios, columns are persona, environment, expectation, priority. Cover every top job with an Achiever and a First-Timer; add one scenario per other expectation that matters for this app; skip the rest and say so.
